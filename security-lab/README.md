# Security Research Lab

A local, consent-based security awareness experiment, separate from the Money Wallet app.

## Run
```sh
cd security-lab
npm install
npm start
```
Open http://127.0.0.1:3000.

## What it does
- Simulates fictional logins and phishing-awareness exercises.
- Shows non-sensitive test events from a local JSON file.
- Does not accept or store passwords, emails, tokens, location, clipboard, or IP data.
- Binds to localhost only; not a public-facing service.

Do not enter real account credentials. This is not a Meta/Facebook verification page.
